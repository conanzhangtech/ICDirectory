> ### **About this Award and Achievement**
> <hr>
> 
> Build Google Cloud Infrastructure for AWS Professionals is an intermediate skill badge in Google Cloud's Infrastructure Modernization track, aimed at practitioners who already work with AWS and want to map that experience onto Google Cloud.
>
> The badge covers core Google Cloud infrastructure — virtual networking, compute instances, identity and access management, and storage — framed throughout by how each service compares to its AWS counterpart.
> 
> Google Cloud skill badges are earned through hands-on labs in a live cloud environment rather than a written exam, and are completed with a final challenge lab in which the tasks are set without step-by-step instructions.
>
